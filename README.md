# Gael Chagas — Advogado Criminalista (landing page)

Site estático (HTML + CSS + JS puro, sem build). Basta abrir `index.html` ou publicar a pasta em qualquer hospedagem (Netlify, Vercel, GitHub Pages, Hostinger...).

Paleta extraída do vídeo da marca: ouro metálico `#A06A2F → #E1A949 → #FDDC7D → #FFE899` sobre azul-marinho profundo `#000106 / #050D1D`.
Tipografia: Cormorant Garamond (títulos) + Montserrat (texto), embutidas em `assets/fonts`.

## Preencher antes de publicar
| O quê | Onde |
|---|---|
| WhatsApp (só dígitos, com DDI+DDD) e telefone exibido | `js/main.js` → `CONFIG` |
| Número da OAB | `index.html` — buscar `OAB/UF nº 000.000` (2 lugares) |
| E-mail, endereço, horário, Instagram | `index.html` — seção `#contato` e rodapé |
| Domínio do e-mail | `contato@seudominio.com.br` |
