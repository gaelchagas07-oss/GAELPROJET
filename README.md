# Gael Chagas — Advogado Criminalista (landing page)

Site estático (HTML + CSS + JS puro, sem build). Basta abrir `index.html` ou publicar a pasta em qualquer hospedagem (Netlify, Vercel, GitHub Pages, Hostinger...).

Segue o **Guia da Marca** (Direito Design):
- Cores: azul `#183547` e dourado `#E0B165` (tons mais escuros do mesmo azul para fundos; `#85612A` para texto dourado sobre fundo claro).
- Fontes: **Montserrat** em todos os textos (arquivo variável em `assets/fonts`). A **Inure Light** aparece apenas no letreiro do logotipo, que é vetorial.
- Logotipo e monograma em SVG (`assets/brand`), extraídos do guia em vetor.
- Pattern oficial (`assets/brand/pattern-a.png`, recorte exato de um período, repete sem emenda) usado como máscara: nítido nas cores da marca (placa do topo) ou tom sobre tom (faixa de chamada e rodapé).
